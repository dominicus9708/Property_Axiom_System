# Release notes

## 0.1.0 — 2026-09-01

Initial generalized Property Axiom System reproducibility package.

### Added

- Standard-library finite model implementation for the generalized typed property core.
- Primitive Axiom I and II independence countermodels.
- Five-way finite status-separation witness.
- Exhaustive Stage-2, Stage-3, and Stage-4 first-branch witnesses.
- Stage-4/Stage-5 comparison-count regression for the displayed witnesses.
- Simple-summary collision with a strict-core-isomorphism obstruction.
- Optional-representation separation witness.
- Finite forward-map composition check.
- Deterministic JSON/CSV outputs, verifier, unit tests, and GitHub Actions workflow.

### Lineage boundary

This repository generalizes the non-axis property core of the earlier `Axioms-for-the-Property-Structure-of-Realized-Axes` work. Axis realization, realized-line rank, bilinear/normal structure, and cyclic axis closure are intentionally excluded from this package and remain preserved in the earlier specialization for possible later use in Structural Gravity.

### Publication status

This is a pre-publication reproducibility package for the rewritten generalized Property Axiom System manuscript. Zenodo DOI/version metadata should be synchronized after the corresponding release is published.
